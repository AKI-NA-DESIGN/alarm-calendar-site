アラームカレンダー

最終更新日：2026年8月5日

アラームカレンダー（以下「本アプリ」）は、利用者のプライバシーを尊重し、個人情報・利用者データを適切に取り扱います。本ポリシーは、本アプリが取得する情報とその利用方法について説明します。

1. 取得する情報

本アプリは、Googleアカウントでのログインを通じて、以下の情報にアクセスします。

  • Googleカレンダーの予定データ（予定の作成・閲覧・編集・削除のため）
  • 共有されたカレンダー（家族共有機能で、共有された予定を表示するため）
  • メールアドレス・基本プロフィール（ログイン状態の管理のため）

このほか、アプリ内に表示する広告の配信のために取得される情報については「4. 広告の配信について」をご覧ください。

2. 情報の利用目的

  • カレンダー上での予定の表示・追加・編集・削除
  • 予定時刻に合わせたアラーム（端末内ローカル通知）の設定
  • 家族間での予定の共有・色分け表示

取得した情報は、上記の機能を提供する目的のみに使用します。

3. データの保存場所

  • 予定データは利用者自身のGoogleカレンダーに保存されます。本アプリ独自のサーバーには保存しません。
  • オフライン表示・高速化のため、予定の一部を端末内にキャッシュとして保存します。
  • ログイン用のトークンは、端末内の安全な領域（Secure Store）に暗号化して保存します。

4. 広告の配信について

本アプリは、無料でのサービス提供を継続するため、アプリ内に広告を表示します。広告の配信には、Google が提供する広告配信サービス「Google AdMob」を利用します。

AdMob は、広告の配信および効果測定のため、以下のような情報を自動的に取得することがあります。

  • 広告識別子（IDFA：Identifier for Advertisers）
  • IPアドレスおよびそれに基づくおおよその地域情報（国・地域レベル）
  • 端末の種類・OSバージョンなどの端末情報
  • 広告の表示回数・タップなどの広告利用履歴

これらの情報の取り扱いについては、Google のポリシーと規約「Google のサービスを使用するサイトやアプリから収集した情報の Google による使用」をご確認ください。

重要：Googleカレンダーのデータは広告に一切使用しません。
本アプリは、Googleカレンダーから取得した予定データ（予定のタイトル・内容・日時・場所・共有カレンダーの情報などを含みます）を、 広告の配信・ターゲティング・効果測定のために使用することは一切ありません。 また、これらのデータを、広告配信事業者を含むいかなる第三者にも提供しません。 広告配信事業者に渡るのは、上記の広告識別子・端末情報などに限られます。

広告のパーソナライズを希望されない場合は、iOS の「設定」→「プライバシーとセキュリティ」→「トラッキング」から、本アプリによるトラッキングを拒否できます。拒否された場合も広告の表示自体は行われますが、利用者の関心に基づかない広告（非パーソナライズ広告）が配信されます。

5. 第三者への提供

本アプリは、取得した情報を第三者に販売・貸与することは一切ありません。

第三者への提供は、上記「4. 広告の配信について」に記載した広告配信のために必要な範囲（広告識別子・端末情報など）に限られます。Googleカレンダーの予定データが第三者に提供されることはありません。

ただし、法令に基づく開示請求を受けた場合は、この限りではありません。

6. Google ユーザーデータの限定利用（Limited Use）

本アプリによる Google API から受け取った情報の使用および他アプリへの転送は、 Google API Services User Data Policy （限定使用要件を含む）に準拠します。本アプリは、Googleカレンダーのデータを上記「2. 情報の利用目的」に記載した機能の提供のみに使用し、 広告目的を含むその他の目的には一切使用しません。 また、Googleユーザーデータを人間が読み取ることはありません（利用者の明示的な同意がある場合、セキュリティ上必要な場合、法令上必要な場合を除きます）。

7. データの削除

  • 本アプリからログアウトすると、端末内のトークンとキャッシュは削除されます。
  • 本アプリのアクセス権は、Googleアカウントのセキュリティ設定からいつでも取り消せます。
